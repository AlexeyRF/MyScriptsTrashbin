# MyScriptsTrashbin

Коллекция скриптов и утилит, объединённых из отдельных репозиториев:

- [crypto-bro](./crypto-bro) — утилиты шифрования (диск, RSA, эллиптические кривые, защищённая почта).
- [gametools](./gametools) — инструменты для работы с графикой, конвертации и вспомогательные скрипты.
- [net-utils](./net-utils) — сетевые утилиты (проверка IP, сканирование портов и IP, сетевые тесты).
- [obfuscation-bro](./obfuscation-bro) — инструменты для обфускации кода Python.
- [physics_manipulator](./physics_manipulator) — физические симуляции (задача трёх тел, траектория кометы, оптика, движение зарядов).
