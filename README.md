# Obfuscation-Bro
Обфускатор для Python программ.
Требования: 
```bash
pip install pycryptodome cryptography pyotp pyqt5 requests flask qrcode[pil]
```
Программа предназначена для защиты python кода от несанкционированного исполнения. Она обфусцирует код и позволяет исполнить его только при соблюдении условий: сервер разработчика согласен на расшифровку, программа имеет правильный хэш и не была изменена и (опционально) введён правильный код TOTP
